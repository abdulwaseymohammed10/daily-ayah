Set up the daily change (one time)

1. Save the pack

  1. In Files, open On My iPhone and make a folder called Wallpapers.
  2. Tap Generate, then Save to Files, and save Ayah.zip in that folder.
  3. Tap the zip in Files. A folder called Ayah appears.

2. Build the Shortcut

  1. In Shortcuts, tap + and name it Daily Ayah.
  2. Add Format Date. Use Current Date, set the format to Custom and type MM-dd (capital MM).
  3. Add Get File from Folder. Pick the Wallpapers folder. For the path type Ayah/, insert Formatted Date, then type .jpg. Turn off Error If Not Found.
  4. Add If, set to File has any value. Delete Otherwise.
  5. Inside the If, add Set Wallpaper Photo with that File. Choose your current wallpaper and Lock Screen only. Turn off Show Preview and Crop to Subject.
  6. Press play once and allow everything it asks.

3. Make it automatic

iOS 27: open the Shortcut, tap Edit, then Automation, and add Time of Day, 12:05 AM, Daily. Under the info button, then Privacy, turn on Allow Running When Locked.

iOS 17 to 26: open Automation, tap +, choose Time of Day, 12:05 AM, Daily, Run Immediately, then pick Daily Ayah.

Add a second time, like 8:00 AM, in case the phone was off.

When you change something

Generate again, delete the old Ayah folder and zip, then save and tap the new zip. The Shortcut stays the same.

If it doesn't change

The Lock Screen must be a normal Photo wallpaper, not Photo Shuffle. Check that a Focus isn't switching Lock Screens. After an iOS update, pick the wallpaper again inside the Shortcut.
